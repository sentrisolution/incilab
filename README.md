## Dillər (AZ / RU / EN)
- AZ səhifələr kökdə, RU `ru/`, EN `en/` qovluğundadır. Hamısını `build.py` yaradır.
- Tərcümələr `i18n.py` faylındadır: `"AZ mətn": ("rusca", "ingiliscə")`.
- `build.py`-da yeni mətn əlavə edib tərcüməsini yazmasanız, həmin mətn `i18n_missing.txt` faylına düşəcək.
